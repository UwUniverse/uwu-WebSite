# Flashlight suggestions

When the flashlight is on, the system shows a quick turn-off suggestion so it can be
disabled after leaving Quick Settings.

## Enable

Go to **uwuSettingsExt → Intelligence → Smart suggestions** and enable “Flashlight
suggestions”.

## Use

1. Turn on the flashlight while the device is unlocked.
2. Tap the turn-off action in the overlay.
3. The system turns off the flashlight and removes the suggestion.

Flashlight suggestions have no fixed timeout. The suggestion disappears when the
flashlight is turned off, the feature is disabled, the action is tapped, or the overlay
is swiped away.

## Scope

- The device must have an available flash.
- The suggestion does not appear on the lock screen or before user initialization is complete.
- The suggestion only provides a turn-off action; it does not otherwise change flashlight state automatically.
