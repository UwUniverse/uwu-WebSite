# Controls menu

The upper-left corner of a Moment has a small control handle. Tap it to expand the handle
into a control menu.

The menu provides three actions:

- Fullscreen: expand the current Moment and restore it as a normal fullscreen task.
- Close: close the current task.
- Compact: shrink the window into compact mode for temporary storage and task switching.

The menu closes automatically when you tap outside it, start dragging, or begin another
interaction.

The bottom control bar also provides shortcuts:

- Tap: perform an in-app back action.
- Double-tap: expand to fullscreen.
- Long-press: close the Moment.
