# Compact mode

Compact mode shrinks a Moment to a lightweight size, which is useful for keeping the
current app nearby while working on other tasks.

Enter compact mode from the top controls menu, or resize a normal Moment to its minimum
size and release it.

## Actions

- Tap a compact window: restore the size it had before entering compact mode.
- Drag: move it within the usable screen area.
- Quickly fling toward or drag past the left or right edge: dock the window and hide part of it at the screen edge.
- Tap a window hidden at the edge: bring it back onto the screen.
- Drag toward the close target: magnetically attach the window to the target and close it on release.
- Fling quickly upward to leave the close target and avoid an accidental close.

Compact windows use spring animations for docking, rebound, and closing. Haptic feedback
is provided when entering or leaving the close target.
