# Settings and scope

Moment settings are located in uwuSettingsExt.

## Master switch

“Enable Moment” controls all Moment entry points. When disabled:

- New Moment launches and conversions are not allowed.
- Existing Moments for the current user are restored to fullscreen.
- Navigation-bar double-tap, MomentArc, and notification-to-Moment behavior stop working.

## Gestures

- Double-tap to enter Moment: control the navigation-bar double-tap entry point.
- Open MomentArc: control the screen-corner gesture.
- Edit MomentArc layout: arrange apps and shortcuts on the left and right sides.

## Open notifications

- Open notifications in Moment: control taps on notification bodies.
- Use in portrait: affect notifications only when the device is in portrait.
- Use in landscape: affect notifications only when the device is in landscape.

## Launch and experience

“Launch apps as Moment” opens an app list and starts the selected app directly as a Moment.

Moment settings are stored separately for each Android user. uwuSettingsExt currently shows
Moment settings only on phones; the page is hidden by default on tablets.
