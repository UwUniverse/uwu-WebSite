# Multiple windows and focus

The system can keep multiple Moments at the same time. When new content is launched from
the app list, MomentArc, a notification, or another entry point, existing Moments do not
need to be closed first.

- Tapping a Moment moves input focus to that window.
- The first tap on the bottom control bar of an unfocused window only activates it, avoiding an accidental back action.
- Each Moment stores its own position, scale, Activity stack, and compact state.
- Restoring or closing one Moment to fullscreen does not close the others.
- Turning off the Moment master switch restores every Moment for the current user to fullscreen.

When windows overlap, the most recently activated task is placed in front. Move or
compact a window you are not using to make room for other apps.
