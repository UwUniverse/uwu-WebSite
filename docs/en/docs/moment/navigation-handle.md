# Double-tap navigation bar

After enabling “Double-tap to enter Moment”, tap the navigation bar at the bottom of the
screen twice in quick succession.

- Double-tap inside an app: convert the current task to a Moment while preserving the current page and Activity stack.
- Double-tap on the home screen: open the app list as a Moment, then choose an app to launch.
- The gesture can be disabled separately in Moment settings.

An overly long press, a drag, or a gesture taken over by another navigation action is not
recognized as a double-tap.
