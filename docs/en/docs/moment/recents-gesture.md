# Swipe-up gesture in Recents

“Pop-Up View gesture” in Launcher settings is a legacy entry point.

After enabling it, perform the Recents gesture from an app and continue dragging upward.
Near the trigger position, Launcher shows the target area and provides visual feedback for
the current task and other Recents cards. Release at the trigger position to open the
current task as a Moment.

“Pop-Up View gesture threshold” adjusts how far the upward swipe must continue. A higher
value requires a longer drag.

This feature will be reimplemented later.
