# 关于本机

uwuAOSP 的“关于本机”把常用硬件、版本和存储信息集中在卡片页面中，并把低频标识信息折叠到独立的“更多设备信息”页面。

## 页面内容

主页面包含：

- 当前系统壁纸构成的模糊头图。
- 可编辑的设备名称。
- 已用和总存储空间，以及可进入存储设置的进度卡片。
- Android 版本和 uwuAOSP 版本。
- 设备型号、芯片、内存、屏幕分辨率、电池容量和内核版本。
- 构建号及原有开发者选项解锁行为。

页面会根据可用宽度在单列和双列之间自适应，不要求设备必须是手机或平板。

## 动态壁纸头图

静态壁纸直接作为头图来源。动态壁纸无法像普通文件一样读取时，Settings 会使用系统保存的最近壁纸快照。壁纸变化后快照会自动刷新，因此切换动态壁纸不需要手动清除 Settings 数据。

头图只用于视觉预览，并叠加模糊和遮罩以保持文字可读。它不会启动动态壁纸渲染器，也不会持续占用壁纸服务。

## 更多设备信息

“更多设备信息”保留法律信息、监管标签、SIM/EID/IMEI、IP 地址、Wi-Fi 与蓝牙地址、运行时间、设备反馈等低频项目。这样主页面只显示日常需要的信息，同时不移除 Android 原有的设备标识入口。

部分卡片会根据设备能力和产品配置隐藏。无法读取的硬件字段显示为未知，不会阻止页面其余内容加载。
