# 系統小圖示

系統小圖示用於切換系統介面使用的圖示資源。目前提供系統預設圖示和 PUI 兩種樣式。

## 使用方式

前往 **uwuAOSP Plus → 介面設定 → 系統小圖示**，選擇：

- **預設**：關閉 uwuAOSP 提供的圖示覆蓋，還原各元件的原始資源。
- **PUI**：啟用 PUI 風格的系統圖示。

系統會透過一次 OverlayManager 交易批次切換所有相容的資源覆蓋，並保存目前選擇。設定、SystemUI、Launcher 等正在執行的介面可能需要重新開啟，或重新啟動對應程序後才會全部更新。

## 工作原理

PUI 圖示以原始碼資源放在 `vendor/uwu/overlay/rro_packages/PUI`，隨 ROM 編譯為可變 RRO。設定頁面只控制已安裝的覆蓋層，不會下載、安裝或執行第三方 APK。

裝置只會啟用目前系統實際存在且通過相容性檢查的覆蓋層。如果產品沒有包含 PUI 資源，或 OverlayManager 拒絕交易，頁面會顯示明確的失敗提示，並保留原有樣式。

PUI 資源來自 **PUI Theme For Stock Android v17.0.218**，原作者為天傘桜；uwuAOSP 將其整理為可從原始碼編譯的系統資源覆蓋。
