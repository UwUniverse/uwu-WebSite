# 應用程式感測器存取

應用程式感測器存取可以限制指定應用程式讀取 Android SensorService 提供的動作與環境感測器資料。

## 設定策略

進入 **uwuSettingsExt → 應用程式感測器存取**，依應用程式名稱或套件名稱搜尋，然後選擇：

- **全部允許**：不增加額外限制。
- **開啟後封鎖 6 秒**：應用程式頁面每次進入前景後，暫時阻止感測器存取 6 秒。
- **永久封鎖**：持續阻止，直到使用者修改策略。

「開啟後封鎖 6 秒」在應用程式頁面重新進入前景時會重新計時。限制解除後，系統不會補發阻止期間遺漏的資料。

## 影響範圍

受影響的應用程式可能無法讀取加速度計、陀螺儀、距離、方向等由 SensorManager 或感測器直連通道提供的資料。

此功能不會限制：

- 相機與麥克風。
- 定位。
- Bluetooth 或 Wi-Fi 掃描。
- UWB、NFC 與 USB。
- 應用程式啟動、網路連線或背景執行本身。

系統原有權限、AppOps、全域感測器隱私開關與背景限制仍會獨立生效。

## 使用限制

策略依 Android 使用者與套件名稱儲存。「開啟後封鎖 6 秒」由應用程式 Activity 回到前景觸發，無介面應用程式或僅啟動服務的情況可能不會觸發。

設定頁面可能顯示符合條件的系統應用程式。限制依賴感測器的系統元件可能造成異常，修改前應確認應用程式用途。
