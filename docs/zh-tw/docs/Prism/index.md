# Prism

Prism 可以擷取目前螢幕，讓使用者框選文字或圖片進行辨識、複製與匯出。

## 啟用

進入 **uwuSettingsExt → 智慧 → Prism**，開啟「三指上滑」。此開關預設關閉。

## 擷取螢幕

在裝置已解鎖且螢幕亮起時，讓三根手指幾乎同時落下並明顯向上滑動。辨識成功後，SystemUI 會擷取預設顯示器的完整畫面，並自動開啟 Prism 擷取頁面。

手勢需要快速、連續且以垂直向上為主。出現第四根手指、某根手指過早抬起、移動距離不足或兩次觸發間隔過短，都會取消操作。

## 選擇內容

進入擷取頁面後，可以在螢幕擷取畫面上建立、移動、縮放或刪除兩類區域：

- **文字區域**：執行 OCR、複製辨識文字，或匯出 TXT/PDF。
- **圖片區域**：儲存到 Pictures，或匯出圖片/PDF。

本機模型依賴 uwuAICore 與已下載的模型，也可以選擇 Prism 內建的中英文 Tesseract。AI Core 無法使用時，Tesseract 仍可能正常運作。

## 檔案儲存

螢幕擷取與 OCR 裁切預設使用暫存檔案，正常退出後會自動清理。只有使用者明確選擇儲存或匯出時，內容才會永久寫入儲存空間；觸發手勢本身不會將螢幕擷取自動儲存到相簿。

## 適用範圍

- 鎖定螢幕、熄屏或非互動狀態下不會擷取，也不會在解鎖後補觸發。
- 目前只擷取預設顯示器，不提供多顯示器選擇。
- 成功手勢會接管目前觸控序列，前景應用程式可能收到一次手勢取消。
- Prism 啟動失敗時，本次暫存螢幕擷取會被刪除。
