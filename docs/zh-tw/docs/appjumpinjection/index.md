# 應用程式跳轉控制

應用程式跳轉控制用於管理一個應用程式開啟另一個應用程式頁面的行為，例如網頁跳轉購物應用程式、內容應用程式啟動商店，或應用程式彼此喚起。

## 啟用

進入 **uwuSettingsExt → 應用程式跳轉**。總開關預設開啟，關閉後所有規則會暫停生效，但不會被刪除。

## 設定規則

可以從三個角度設定跳轉：

- 某個應用程式作為來源，開啟其他應用程式時使用的規則。
- 某個應用程式作為目標，被其他應用程式開啟時使用的規則。
- 精確的「來源應用程式 → 目標應用程式」配對規則。

每項規則可以設定為：

- **永遠允許**：直接開啟目標頁面。
- **詢問**：跳轉前顯示確認視窗。
- **永遠封鎖**：中止跳轉並顯示簡短提示。

精確配對規則優先於來源與目標的通用規則。

## 詢問視窗

詢問視窗會顯示來源與目標應用程式的名稱及圖示。選擇允許或不允許後，本次跳轉會依所選結果處理。

勾選「記住我的選擇」會把結果儲存為這兩個應用程式之間的配對規則；不勾選則只對本次有效。點按視窗外或按返回鍵等同取消，不會開啟目標應用程式，也不會儲存規則。

## 適用範圍

此功能只管理 Activity 頁面啟動，不會阻止 Service、Broadcast、Provider、Binder 或網路通訊。同一應用程式內部頁面、系統來源、啟動器、系統解析器、權限控制器、檔案或相片選擇器等必要流程會被豁免。

需要向來源頁面返回結果的啟動通常保留 Android 原有行為。解除安裝應用程式不會自動刪除舊規則，相同套件名稱重新安裝後，舊規則可能再次生效。
