# MomentArc

MomentArc 是從螢幕底角呼出的弧形快速啟動器。啟用後，從左下角或右下角向螢幕內側上滑即可開啟對應一側的 MomentArc。

手指在圖示之間移動時會反白目前目標，放開後以 Moment 啟動所選應用程式或捷徑。取消手勢時不會啟動內容。

## 自訂配置

Moment 設定頁提供 MomentArc 配置編輯器。

- 左側與右側擁有各自的配置。
- 可以加入應用程式與應用程式捷徑。
- 支援搜尋應用程式或捷徑。
- 可以點按或拖曳項目至目標位置。
- 長按既有位置可以清除內容。
- 「更多應用程式」位置會開啟完整應用程式清單。

MomentArc 目前只回應預設顯示器的底角手勢。
