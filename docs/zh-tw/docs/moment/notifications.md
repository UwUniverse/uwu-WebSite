# 開啟通知

啟用「在 Moment 中開啟通知」後，點按符合條件的通知本體會以 Moment 開啟通知對應的頁面。

通知右下角會顯示「以全螢幕開啟」按鈕。點按該按鈕會強制以全螢幕開啟相同內容，即使該應用程式已存在 Moment 工作。

## 方向選項

通知開啟可以分別控制：

- 在直向螢幕時使用
- 在橫向螢幕時使用

裝置旋轉後，已有通知會根據目前方向更新點擊行為與右下角按鈕。

## 支援範圍

- 優先開啟通知提供的 Activity 頁面。
- 通知沒有有效 Activity 入口時，會嘗試開啟應用程式主介面。
- 支援一般通知、多媒體通知、常駐通知、橫幅通知與鎖定螢幕通知。
- 分組摘要、自訂通知配置或沒有可啟動 Activity 的通知會保持原始行為。
- 鎖定螢幕與獨立工作設定檔會先完成身分驗證，再依選取的視窗模式開啟。
- 只有宣告自動清除的通知，才會在成功開啟後自動消失。

關閉總開關或目前方向選項後，通知會恢復 Android 原有的點擊與氣泡行為。
