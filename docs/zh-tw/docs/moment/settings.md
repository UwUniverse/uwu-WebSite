# 設定與適用範圍

Moment 設定位於 uwuSettingsExt。

## 總開關

「啟用 Moment」控制所有 Moment 入口。關閉後：

- 不再允許新的 Moment 啟動或轉換。
- 目前使用者已有的 Moment 會恢復至全螢幕。
- 導覽列雙擊、MomentArc 與通知 Moment 行為停止生效。

## 手勢

- 雙擊進入 Moment：控制導覽列雙擊入口。
- 開啟 MomentArc：控制螢幕底角手勢。
- 編輯 MomentArc 配置：安排左右兩側的應用程式與捷徑。

## 開啟通知

- 在 Moment 中開啟通知：控制通知本體點擊行為。
- 在直向螢幕時使用：只影響裝置處於直向時的通知。
- 在橫向螢幕時使用：只影響裝置處於橫向時的通知。

## 啟動與體驗

「以 Moment 啟動應用程式」會開啟應用程式清單，並直接以 Moment 啟動所選應用程式。

Moment 設定依 Android 使用者分別儲存。uwuSettingsExt 目前只在手機裝置上顯示 Moment 設定入口，平板裝置預設隱藏此功能頁面。
