# 多視窗與焦點

系統可以同時保留多個 Moment。透過應用程式清單、MomentArc、通知或其他入口啟動新內容時，已有 Moment 不需要先關閉。

- 點按一個 Moment 會將輸入焦點切換至該視窗。
- 未聚焦視窗第一次點按底部操作列只負責啟用視窗，避免誤觸發返回。
- 每個 Moment 分別儲存自己的位置、比例、Activity 堆疊與摺疊狀態。
- 將某個 Moment 恢復至全螢幕或關閉時，不會同時關閉其他 Moment。
- 關閉 Moment 總開關時，目前使用者的所有 Moment 都會恢復至全螢幕。

多個視窗重疊時，最近啟用的工作會位於前方。可以先移動或摺疊暫時不用的視窗，為其他應用程式留出空間。
