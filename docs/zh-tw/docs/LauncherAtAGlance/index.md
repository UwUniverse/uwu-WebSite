# Launcher 一覽

Launcher 一覽會在第一個主畫面頂端顯示日期、天氣、下一個鬧鐘、計時器和目前媒體資訊。它是 Launcher 工作區的一部分，不會佔用一般小工具插槽。

## 顯示內容

預設一覽頁面會依可用資料組合顯示：

- 日期，點選後開啟行事曆。
- 目前天氣和預報，點選後開啟天氣頁面。
- 下一個鬧鐘。
- 正在執行的計時器。
- 目前媒體標題、副標題和封面，點選後開啟播放應用程式。

有媒體內容時，可以左右切換一覽頁和媒體頁。只有存在多個頁面時才顯示頁面指示器。日期、地區、時區、鬧鐘和媒體狀態變更會立即更新。

## 設定

開啟 Launcher 設定：

- **顯示一覽**控制整個第一個主畫面的一覽區域，預設開啟。
- **使用 Smartspacer**允許已安裝並授權的 Smartspacer 提供卡片，預設關閉。

Smartspacer 不存在、已停用或權限檢查失敗時，Launcher 會自動回到內建一覽，不會留下空白區域。

## 資料來源

日期和鬧鐘來自 Android 系統服務，天氣、計時器和媒體資訊透過系統端提供者讀取。Launcher 不會自行連線要求天氣資料。裝置或產品沒有提供某類資料時，對應項目會隱藏，其餘項目仍會顯示。

Launcher 設定和開關會隨 Launcher 偏好設定備份。清除 Launcher 資料會還原預設值。
