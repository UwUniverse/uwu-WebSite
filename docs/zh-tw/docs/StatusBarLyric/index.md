# 狀態列歌詞

狀態列歌詞可以顯示相容音樂應用程式的即時歌詞，並可選擇同時顯示翻譯。

## 設定

使用前需要完成以下設定：

- 開啟狀態列歌詞總開關。
- 將允許提供歌詞的音樂應用程式加入允許清單。
- 選擇覆蓋狀態列起始側，或顯示在時鐘右側。
- 依需求開啟翻譯與應用程式圖示。

總開關預設關閉，允許清單預設為空。空白清單表示不接受任何應用程式的歌詞。

## 顯示位置

### 覆蓋狀態列左側

歌詞出現時，會覆蓋整個狀態列左半邊的其他內容，讓歌詞獲得更大的顯示空間。

### 時鐘右側

時鐘繼續顯示，歌詞位於其右側。歌詞出現時，通知應用程式圖示區域會暫時隱藏。使用者可以選擇是否顯示提供歌詞的應用程式圖示。

主歌詞與翻譯均為單行捲動文字，歌詞更新時帶有上下切換動畫。點按或觸控歌詞會暫時隱藏，約 1.2 秒後恢復。

## 應用程式相容性

音樂應用程式必須支援 MediaSession，絕大多數 App 都支援此特性。
系統會自動取得歌詞及其翻譯（如果有），以及音樂應用程式的單色圖示，顯示在指定位置。
