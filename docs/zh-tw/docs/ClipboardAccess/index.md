# 應用程式剪貼簿存取權限

應用程式剪貼簿存取權限會在應用程式讀取或寫入系統剪貼簿前套用額外的使用者政策。它不會取代 Android 原有的權限、AppOps 檢查或系統豁免，而是在這些檢查通過後決定是否允許這次操作。

## 設定政策

前往 **uwuAOSP Plus → 隱私權與安全性 → 應用程式剪貼簿存取權限**，即可為每個應用程式選擇：

- **允許**：維持 Android 的預設行為。
- **詢問**：應用程式存取剪貼簿時顯示確認視窗。
- **拒絕**：直接拒絕應用程式的讀取和寫入要求。

政策會依 Android 使用者和套件名稱寫入 `Settings.Secure`，重新啟動後仍然有效。沒有個別規則的應用程式會遵循全域預設值。

## 詢問視窗

詢問視窗會顯示應用程式名稱，並區分讀取和寫入要求。

- 未勾選「寫入永久規則」時，拒絕只影響目前要求，系統會在短時間內節流以避免重複視窗；允許會授予約 10 秒的暫時存取權限。
- 勾選後，選擇結果會儲存為應用程式的永久規則。
- 關閉視窗或按返回鍵等同於拒絕目前要求，不會儲存規則。

系統會限制同一應用程式在短時間內重複顯示視窗。在使用者決定前，目前的剪貼簿呼叫不會被放行。

## 適用範圍

這項政策涵蓋 `ClipboardService` 處理的文字及剪貼簿資料讀寫。Android 為輸入法、系統元件、目前前景應用程式及其他受信任情境提供的原生豁免仍然有效，因此並非每次內部剪貼簿呼叫都會顯示視窗。

依賴背景讀取剪貼簿的應用程式，在選擇「詢問」或「拒絕」後，可能無法使用自動填入、跨裝置同步或剪貼簿歷程功能。
