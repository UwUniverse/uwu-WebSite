# 自訂字型

自訂字型會將使用者匯入的字型註冊到 Android 字型服務，並覆寫系統預設的 `sans-serif` 字型族。新啟動的應用程式會使用所選字型；重新啟動裝置後可更新所有系統介面。

## 匯入字型

前往 **uwuAOSP Plus → 介面設定 → 自訂字型**，即可選擇：

- 單一 TTF 或 OTF 字型。
- 包含多個 TTF/OTF 檔案的 ZIP 壓縮檔。

ZIP 會在本機解壓縮。有效字型會長期儲存在應用程式私有的 `CustomTTF` 目錄，並依 PostScript 名稱、字重和樣式列出。損壞檔案、非字型檔案及簽章無效的檔案會被忽略。

為避免異常壓縮檔耗盡儲存空間，匯入上限為 256 個壓縮檔項目、128 個字型、單一字型 64 MiB，以及字型總量 256 MiB。

## 預覽與套用

選取字型後，頁面會用該字型顯示以下預覽：

```text
老人正夢見獅子。
The quick brown fox jumps over the lazy dog.
0123456789
いろはにほへと ちりぬるを
```

點選「套用所選字型」後，系統字型服務會驗證並安裝字型。失敗時頁面會顯示具體原因，例如檔案無效、不支援的簽章、儲存空間不足或系統字型服務無法使用，而不是只顯示內部錯誤碼。

## 還原預設字型

選擇「還原預設字型」會移除系統的自訂字型覆寫，並清空 `CustomTTF` 中的匯入檔案。還原後，新啟動的應用程式會使用系統預設字型；重新啟動可讓所有介面同步更新。

字型檔案只會在裝置本機處理，不會上傳。部分應用程式使用自帶字型或自行繪製資源，因此不一定會跟隨系統字型變更。
