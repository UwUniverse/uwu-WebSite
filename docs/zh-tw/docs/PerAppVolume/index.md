# 個別應用程式音量

個別應用程式音量為目前正在播放聲音的應用程式提供獨立增益，不會改變全域媒體音量。當音樂、遊戲、導航或通話輔助音效同時播放時，可以分別調整它們的音量。

## 啟用

前往 **設定 → 音效與震動 → 音訊 → 控制特定應用程式的音量**。這個開關預設關閉。

啟用後，系統音量面板會顯示應用程式音量入口。開啟後可以為目前存在播放軌道的應用程式分別設定 0–100 的音量。應用程式停止播放並釋放音訊軌道後，可能暫時從清單中消失。

## 工作原理

SystemUI 從 AudioManager 取得目前的應用程式音訊軌道，並把 0–100 的介面數值轉換成 AudioFlinger 使用的 `0.0–1.0` 增益。AudioFlinger 在混音階段將應用程式增益與媒體串流音量、連接埠音量相乘，因此：

- 調低某個應用程式不會改變其他應用程式的音量。
- 系統媒體音量仍然控制最終整體音量。
- 同一套件名稱建立的新播放軌道會繼承執行中的 AudioFlinger 程序保存的應用程式增益。

這個介面受 `MODIFY_AUDIO_ROUTING` 權限保護，一般第三方應用程式不能直接修改其他應用程式的音量。

## 限制

應用程式增益保存在 AudioFlinger 的執行狀態中，不是長期使用者設定。音訊服務或裝置重新啟動後，應用程式音量會恢復預設值。沒有獨立音訊軌道、使用特殊直通路徑或由其他程序代為播放的應用程式，可能不會以預期名稱出現在清單中。
