# 外接螢幕桌面

外接螢幕桌面會將 USB-C、HDMI 及支援的虛擬顯示器交給 Android 桌面模式。應用程式會在外接螢幕上以可移動、可縮放的自由視窗執行，工作列和視窗標題列由系統桌面模式提供。

## 啟用

前往 **uwuAOSP Plus → 系統與桌面 → 外接螢幕桌面**，開啟總開關。

頁面還提供兩個獨立選項：

- **遮蓋內建螢幕**：外接桌面執行時，在內建螢幕顯示黑色連線提示；最後一個外接螢幕中斷後自動還原。
- **允許 scrcpy 虛擬螢幕**：允許 `scrcpy --new-display` 建立的受信任虛擬螢幕進入桌面模式。一般螢幕鏡像不會改變內建螢幕配置。

## 使用方式

連接支援視訊輸出的 USB-C 或 HDMI 顯示器後，系統會將鍵盤和滑鼠焦點指向外接桌面。也可以使用支援新顯示器功能的 scrcpy：

```sh
scrcpy --new-display=1920x1080
```

系統會將受支援的投影顯示器視為平板桌面，並為窄螢幕或直向裝置計算適合的密度和方向。它會重用 Android 內建的自由視窗、工作列、視窗標題列和工作管理，不會執行另一套桌面環境。

## 中斷連線後還原

最後一個外接桌面顯示器中斷後，系統會：

- 移除內建螢幕上的黑色提示。
- 還原內建螢幕和觸控互動。
- 將焦點返回內建螢幕。
- 結束只屬於已移除顯示器的桌面工作階段。

不支援自由視窗或多顯示器的應用程式，仍可能以受限尺寸、固定方向或相容模式執行。
