# 音樂建議

連接耳機或其他個人音訊裝置後，系統可以建議開啟使用者指定的音樂應用程式。

## 選擇應用程式

進入 **uwuSettingsExt → 智慧 → 智慧建議**，在音樂建議中選擇一個應用程式。完成選擇後，系統會儲存目標應用程式並開啟音樂建議。

只開啟建議開關而沒有選擇實際應用程式時，不會顯示音樂建議。

## 使用

連接支援的音訊裝置後，浮層會顯示所選音樂應用程式的圖示與啟動操作。點按即可開啟應用程式。

支援的裝置包括：

- 有線耳機與耳麥。
- USB 耳麥。
- Bluetooth SCO 或 A2DP 裝置。
- BLE 耳機、喇叭與廣播裝置。
- 助聽器。

同一次持續連線不會反覆顯示建議。建議會在約 30 秒後自動消失；中斷裝置連線、關閉功能、點按或滑動也會結束建議。

## 適用範圍

- 目標應用程式必須已安裝、具有啟動器入口且可以讀取圖示。
- 建議只負責開啟應用程式，不會自動開始播放音樂。
- 鎖定螢幕時不會顯示建議，也不會在解鎖後補顯示。
- 更換目標音樂應用程式後，下次符合條件時會使用新的應用程式。
