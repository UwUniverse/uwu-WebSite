# 智慧建議

智慧建議會根據目前內容或裝置狀態顯示快速操作，減少複製、切換應用程式與手動尋找功能的步驟。

進入 **uwuSettingsExt → 智慧 → 智慧建議**，可以分別開啟不同類型的建議。所有建議預設關閉；首次進入頁面會準備剪貼簿與驗證碼的預設規則，但不會自動開啟功能。

## 建議類型

- [剪貼簿應用程式建議](./clipboard-apps.md)：複製連結或文字後，建議使用符合的應用程式開啟。
- [SMS 驗證碼建議](./sms-codes.md)：收到驗證碼簡訊後，提供複製或填入操作。
- [手電筒建議](./torch.md)：手電筒開啟時提供快速關閉操作。
- [音樂建議](./music.md)：連接耳機後，建議啟動指定的音樂應用程式。

## 顯示方式

智慧建議會重用系統剪貼簿浮層，不屬於通知。新的建議會取代目前浮層，SystemUI 重新啟動後不會恢復。

建議只會在裝置已解鎖且使用者設定完成時顯示。鎖定螢幕期間錯過的建議，不會在解鎖後補顯示。

## 適用範圍

智慧建議只提供快速操作，不會自動開啟應用程式、填入驗證碼、關閉手電筒或播放音樂。目標應用程式不存在、輸入框不支援填入、內容未符合規則或裝置不具備對應能力時，建議可能不會出現或無法完成操作。
