# SMS 驗證碼建議

收到一般 SMS 並辨識出驗證碼後，系統會顯示驗證碼浮層，提供複製與填入操作。

## 啟用與設定

進入 **uwuSettingsExt → 智慧 → 智慧建議**，開啟 SMS 驗證碼建議。

在規則頁面中可以開啟、新增、編輯、刪除或重設驗證碼規則。系統會按照規則排列順序尋找，使用第一個符合的結果。

## 操作

- **複製**：將驗證碼寫入剪貼簿，不會再次顯示一般剪貼簿浮層。
- **填入**：嘗試將驗證碼提交至目前聚焦的輸入框。

驗證碼建議沒有固定逾時時間。完成複製、成功填入、滑動關閉或由系統關閉後，浮層才會消失。

## 適用範圍

- 只處理一般 SMS，不處理所有端口簡訊或其他訊息應用程式的通知。
- 「填入」取決於目前輸入法與聚焦輸入框是否接受文字。
- 填入失敗時不會自動改為複製，使用者仍可手動選擇複製。
- 鎖定螢幕時不會顯示驗證碼建議，也不會在解鎖後補顯示。
- 規則無效或簡訊內容未符合規則時，不會顯示建議。
