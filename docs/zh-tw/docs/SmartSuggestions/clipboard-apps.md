# 剪貼簿應用程式建議

複製符合規則的連結或文字後，系統剪貼簿浮層會顯示目標應用程式的操作按鈕。點按按鈕會嘗試用該應用程式開啟符合的內容。

## 啟用與設定

進入 **uwuSettingsExt → 智慧 → 智慧建議**，開啟剪貼簿應用程式建議。

在規則頁面中可以：

- 開啟或關閉單條規則。
- 新增與編輯自訂規則。
- 刪除規則。
- 還原預設規則。

預設規則涵蓋淘寶、百度網盤、123 雲盤、嗶哩嗶哩、抖音、拼多多、京東、小紅書、微博、知乎、網易雲音樂、QQ 音樂、閒魚、支付寶、釘釘、夸克與飛書等應用程式。

## 使用

1. 在任意應用程式中複製連結或文字。
2. 內容符合已啟用的規則後，剪貼簿浮層會顯示目標應用程式按鈕。
3. 點按按鈕，使用目標應用程式開啟符合的內容。

目標應用程式無法直接處理符合的內容時，系統可能改為開啟應用程式首頁。浮層通常會在約 6 秒後消失；使用者與浮層互動會重新計算顯示時間。

## 適用範圍

- 目標應用程式必須已安裝、已啟用且可以啟動。
- 多條規則同時符合時，只顯示第一個有效建議。
- 從目標應用程式自身複製內容時，不會建議再次開啟同一個應用程式。
- 連結主要支援 HTTP、HTTPS、`dtk://` 與 `m.tb.cn`；其他符合的內容可能只能開啟應用程式首頁。
- 無效規則會被忽略，不影響其他有效規則。
